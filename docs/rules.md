# Правила проекта

## Продукт

Сохранять порядок источников и трассируемость каждого раздела. Не угадывать неразборчивый текст. Не объединять противоречащие сведения в безусловный факт. Не считать уверенность модели измерением правильности. Не включать неиспользуемые картинки в лекцию автоматически.

## Архитектура

Разделить импорт, разбор Markdown, клиент модели, извлечение, суммаризацию и экспорт. UI не должен содержать бизнес-логику. Модель и endpoint задавать конфигурацией. Кэш версионировать по всем влияющим входам. Не хранить chain-of-thought: достаточно результатов, метаданных и ошибок.

## Проверки и воспроизводимость

Обычные тесты работают без GPU и сети. Live eval запускается явно. Фиксировать модель/digest, параметры, версию промпта, набор и commit при наличии. Отмечать непроверенные эталоны. Сравнивать варианты на одинаковых примерах; отложенные примеры не использовать для настройки.

## Импорт и приватность

Ограничить размер ZIP, количество файлов, распакованный размер и изображения. Запретить traversal, абсолютные пути и симлинки. Не загружать удалённые изображения автоматически. Содержимое заметок не исполнять и не подставлять в команды оболочки. Логи по умолчанию содержат метаданные, а полные материалы — только локальный opt-in debug.
