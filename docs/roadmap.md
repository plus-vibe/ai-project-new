# Задачи реализации

Статус пунктов отражает выполненные части; наличие скрипта не означает завершённый baseline или MVP.

## Приоритет: рабочий веб-MVP

По новой задаче пользователя приоритет смещён с подготовки сравнения моделей на готовый пользовательский сценарий. Реализован «Лист»: ZIP → упорядоченные блоки → суммаризация слайдов с заметками локальной 4B → просмотр источников → Markdown. Запуск: tools/serve.py или start.cmd. Есть фронтенд без сборки, история, очередь, кэш, предупреждения и тесты с подставной моделью. Вместо Streamlit выбран HTML/CSS/JS без установки пакетов. Формальная оценка по golden set и сравнение 4B/8B остаются отдельными открытыми задачами; критерии качества ниже не считаются достигнутыми из-за наличия приложения.

Уточнение требований: результат — единый summary всей лекции на основе скриншотов И подписей, а не отдельный пересказ каждого блока. Реализован pipeline v2: полноценное чтение всех изображений, анализ соседних источников по темам, общее введение и экспорт. Вход можно передать как MD с изображениями, папку или ZIP. Отсутствующие изображения блокируют запуск/экспорт; их можно добавить отдельно. Интерфейс заменён нейтральной страницей «Summary лекции» с крупным текстом. Наличие извлечения и ссылок по-прежнему не означает проверенную фактическую точность.

Улучшение рабочего сценария: реализована запоминаемая папка вложений с доступом только на чтение. При загрузке одного MD подбираются только его изображения, по пути/единственному имени; неоднозначность не скрывается. Настройка хранится в браузере, без поддержки File System Access API действует на сессию. Новый интерфейс «Лекта» с боковой библиотекой, карточкой папки, областью чтения и оглавлением. Проверка качества модели остаётся отдельной задачей.
