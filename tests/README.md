# Тесты

`test_run_extraction.py` проверяет ограничения локального endpoint, запрет перенаправлений, отклонение пустого/обрезанного ответа, передачу ошибок HTTP/timeout и выбор источников из синтетического ZIP с исключением orphan и отказом при неоднозначности. Запуск без GPU и сети: `python3 -X utf8 -m unittest discover -s tests -p 'test_*.py'` (Windows-команда приведена в README).

Отдельная проверка запуска с подставным клиентом подтверждает: timeout даёт ненулевой код, manifest со статусом failed и отсутствие файла успешного ответа. Сейчас шесть тестов.

`test_app.py` проверяет порядок и связывание блоков, заголовки, кодовые блоки, wiki/Markdown-вложения, ограничения ZIP и отказ от внешних изображений; полный сценарий с подставной моделью, кэш, восстановление истории, ошибку/повтор, HTTP-загрузку/экспорт, ограничения Origin/Host. Регрессии: отсутствие изображений блокирует запуск и скачивание старого результата; изображения можно добавить в исправленную копию; чтение скриншотов получает именно изображения без подмены подписями; анализ получает извлечение и подписи; итог общий, источники не теряются и не переставляются; текстовая лекция работает без vision-запросов. Используются временные файлы, синтетические данные и локальный HTTP; реальная Ollama и внешняя сеть не требуются. Всего 14 тестов.

Live-проверки с настоящей Ollama выполняются отдельно и не входят в эту команду.
