# Golden set

cases.json содержит каталог сценариев, а не готовую эталонную разметку. Все reviewed=false. Заполнить required_facts, exact_fragments и forbidden_errors после ручного просмотра источников; для reviewed=true required_facts не должен быть пустым.

По решению пользователя текущий набор `0.2-rag-draft` относится к лекции про RAG и заменяет предыдущую подборку. Исходная лекция хранится локально вне Git в data/private/test_note.zip: 32 Obsidian-вставки, 33 PNG и одно неиспользуемое изображение. Файлы лекции в этот каркас не включены. Локальная подборка шести изображений и черновик критериев находятся в artifacts/m1-review-rag/review.md; это ещё не утверждённый эталон. Заголовок без комментария и лишнее вложение проверяют структуру/импорт; их нельзя смешивать с оценкой полноты содержательных слайдов.

Следующий формат оценки: по каждому case записать покрытие каждого факта, критические ошибки, неподтверждённые утверждения, порядок и допустимость источников. Автоматически проверять точные фрагменты/ссылки, семантические факты пока проверять человеком. Оценщик ещё не реализован.

Пробный сбор ответов: `python3 -X utf8 tools/run_extraction.py data/private/test_note.zip --save-responses`. Полная Windows-команда и параметры описаны в README. Скрипт использует только изображения, не передаёт заметки и пропускает orphan; результаты с метаданными сохраняет локально в artifacts/runs/. Статус ok означает завершённый непустой ответ, а не правильность. Непроверенный статус набора сохраняется до явной сверки фактов человеком.

Отдельно добавить негативные синтетические ZIP и held-out лекцию. Делить примеры по исходным лекциям, чтобы соседние слайды не создавали утечку между development и held-out.
