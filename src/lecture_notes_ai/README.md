# Код локального MVP

`app.py` — импорт и проверка комплектности лекции, ограниченный парсер Markdown, история заданий, очередь и экспорт. `pipeline.py` — отдельное чтение всех скриншотов без подписей, анализ тематических групп вместе с подписями, общее введение к summary. Извлечение доступно для проверки каждого источника, не сокращается заранее. Источники и порядок назначает приложение; содержимое моделей и лекций остаётся данными.

Запускать из корня через `python3 -X utf8 tools/serve.py` (Windows-команда и start.cmd описаны в README). HTTP-слой расположен в tools/serve.py, интерфейс — в web/. Браузер принимает MD с изображениями/папку и локально упаковывает файлы в ZIP; готовый ZIP также принимается. Отсутствующие скриншоты блокируют запуск и экспорт. Добавление изображений создаёт исправленную копию. Повторно используются проверка ZIP и локальный HTTP-клиент из tools/. Все материалы, извлечения, summary и кэш хранятся в artifacts/app/ вне Git. Внешних зависимостей нет.
