# Место проектных skills

Пока активных skills нет. Заготовки лежат в docs/skill-templates/*.md.template. В своей рабочей области проверьте их и создайте .agents/skills/<name>/SKILL.md, убрав суффикс .template. Они предназначены только этому репозиторию, не требуют глобальной установки. Проверяйте обнаружение skills вашей версией Codex.
